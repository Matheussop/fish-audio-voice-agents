# 08. MCP da Fish Audio no Claude Code

No vídeo: **12:08**.

Pra conversar com a Fish Audio direto do Claude Code, sem script:

```bash
claude mcp add --transport http fish-audio https://api.fish.audio/mcp
```

Depois rode `/mcp` no Claude Code e autentique. A partir daí dá pra pedir em texto: buscar voz, gerar fala, ver os créditos.

O uso pelo MCP gasta crédito da conta.
